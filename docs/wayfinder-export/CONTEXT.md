# Nestplay
<!-- Exported Wayfinder snapshot. -->

Nestplay is a private home media library and a way to browse personalized YouTube recommendations and select videos for local downloading.

## Language

**Local library**:
The completed downloaded videos and movies supplied through a watched folder that are available for playback.
_Avoid_: YouTube feed

**YouTube Home**:
The personalized recommendations associated with the single connected YouTube account, including additional pages of results.
_Avoid_: Subscriptions, trending

**Download queue**:
The selected videos waiting to download or currently downloading; a queued video is not yet a playable library item.

**Watched folder**:
A folder where the user places movie files for automatic library discovery.

**Spanish subtitle match**:
A Spanish subtitle track selected for compatibility and synchronization with a particular video, regardless of Spanish regional variant.

**Original-language metadata**:
Movie titles and descriptions presented in the movie's original language, distinct from the user's preferred subtitle language.

**Storage reserve**:
The 20 GB of free disk space at which media downloads and temporary conversion writes must stop and the client must be informed.

**Temporary playback copy**:
Transient converted media used to play an incompatible original, without retaining another complete version in the library.
